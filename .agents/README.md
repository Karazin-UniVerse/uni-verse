# Agent Skills and Reusable Roles

This directory contains reusable AI agent skills and role templates for the Karazin UniVerse monorepo.

## Structure

- `skills/`: Project and community agent skills (standard `SKILL.md` format).
  - `karazin-edean/`: Guidelines and anti-pattern prevention for UniVerse E-Dean development.
  - `skill-creator/`: Anthropic skill creator and benchmarking framework.
  - `brainstorming/`: Structured ideation framework.
  - `frontend-design/`: Frontend design and styling instructions.
  - `web-design-guidelines/`: Vercel Labs web design heuristics.
- `roles/`: Reusable agent role definitions for multi-agent workflows.
  - `core-architect.md`: Domain contracts and grade scale utilities.
  - `ui-specialist.md`: Una UI component implementation.
  - `backend-gateway-dev.md`: NestJS Moodle proxy integration.
  - `quality-auditor.md`: SonarCloud, linting, and test auditing.

## About this project

Karazin UniVerse is a university student portal. It is a pnpm/Turborepo
monorepo with a Next.js/React frontend in packages/uni-hub, a shared Una UI
library in packages/ui, shared contracts and domain calculations in
packages/core, a NestJS API in packages/backend, and Prisma data access in
packages/database.

The backend integrates with Moodle and the E-Dean portal. Student data,
credentials and academic records are sensitive. Grade calculations, status
transitions and authorization must retain their existing business rules.

## What to ask about

- Focus on the behavior changed by this push and its relevant callers.
- Prefer concrete consequences involving permissions, validation, grading,
  caching, error handling and frontend/backend contracts when the code supports them.
- For tooling changes, ask about installation scope, preservation of existing
  hooks, credential handling, cancellation and recovery.
- Do not ask for file names, translation keys, incidental style values or
  implementation trivia. Pure documentation or cosmetic edits need no quiz
  unless they change behavior or operational requirements.

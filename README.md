# UniVerse
Університетська B2B SaaS-платформа для цифровізації освітніх, академічних та адміністративних процесів.

## Стек
- Frontend: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL + Prisma
- Monorepo: pnpm workspaces + Turborepo

## Запуск
```bash
pnpm install
cp .env.example .env
pnpm dev
```
